## 📌 About

**B Vibe Cafe Billing System** is a fully offline point-of-sale application built with Flutter. This project was developed based on direct client requirements — the cafe needed a fast, reliable billing system that works without an internet connection and supports keyboard shortcuts for efficient order management during busy hours.

---

## ✨ Features

- ✅ Fully offline system — no internet dependency
- ✅ Keyboard shortcut navigation for fast billing
- ✅ Simple and clean UI for cafe staff
- ✅ Bill printing support
- ✅ Menu and order management
